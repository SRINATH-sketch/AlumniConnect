# Alumni Connect

## 📌 Overview

**Alumni Connect** is a web-based platform designed to bridge the gap between **students and university alumni**.

The platform provides a common space where students can connect with alumni, explore alumni information, and build professional and academic relationships.

The main goal of Alumni Connect is to create a digital community that encourages **mentorship, networking, knowledge sharing, and career guidance**.

## 🎯 Objectives

* Connect students with university alumni.
* Provide a platform for alumni networking.
* Help students gain career guidance and mentorship.
* Allow users to register and log in to the platform.
* Provide a simple dashboard for users.
* Improve communication between students and alumni.
* Create a centralized platform for alumni-related information.

## ✨ Features

### 👤 User Registration

Users can create an account by providing their required details.

### 🔐 Login

Registered users can securely log in to access the platform.

### 📊 Dashboard

Users can access the dashboard after logging in and navigate through the available features.

### 🤝 Alumni Networking

Students can use the platform to discover and connect with alumni.

### 📚 Information Sharing

The platform can be used to share useful academic, career, and professional information.

### 🎓 Student-Alumni Interaction

The project focuses on creating a bridge between current students and alumni for guidance and networking.

## 🛠️ Technologies Used

* **HTML5** – Web page structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Client-side functionality
* **Firebase** – Authentication and backend-related services
* **Git & GitHub** – Version control and project collaboration

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SRINATH-sketch/AlumniConnect.git
```

### 2. Open the project

Navigate to the project directory:

```bash
cd AlumniConnect
```

Open the project in Visual Studio Code:

```bash
code .
```

### 3. Run the project

Open the required HTML file from the project in a browser, or use the **Live Server** extension in Visual Studio Code.
